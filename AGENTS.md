# AGENTS.md

Context for AI agents and developers working on the CalmEars waitlist site.

## What this project is

A one-page, pre-launch waitlist site for CalmEars: earbuds being designed for
misophonia. The hardware does not exist yet, so the site's only conversion goal
is an email address. There is no PLAN.md — the site is feature-complete for its
purpose. Treat additions as product decisions, not gaps.

## Architecture

TanStack Start (React 19) on Netlify. One route, one server module, one table.

```
db/
  schema.ts                 # waitlist_signups — email + created_at, nothing else
  index.ts                  # Drizzle client (drizzle-orm/netlify-db, zero config)
netlify/database/migrations # generated by drizzle-kit, applied by Netlify on deploy
public/img/                 # AI-generated concept renders (committed, not built)
scripts/generate-images.mjs # one-off image generation via Netlify AI Gateway
src/
  components/
    Faq.tsx                 # native <details> accordion, content lives here
    SoundConsole.tsx        # the interactive trigger demo
    TriggerMarquee.tsx      # scrolling band of trigger words
    WaitlistForm.tsx        # email form, owns its own request state
    Wordmark.tsx            # logotype + waveform glyph
  routes/
    __root.tsx              # document shell, metadata, font links
    index.tsx               # the whole page; section content in STEPS / STAGES
  server/
    waitlist.ts             # joinWaitlist + getWaitlistCount server functions
  styles.css                # Tailwind v4 @theme tokens, keyframes, bar styles
```

`src/routeTree.gen.ts` is generated by the TanStack plugin during dev/build and is
git-ignored. Do not write it by hand.

## Non-obvious decisions

- **Email only, on purpose.** The owner chose a single-field form for conversion.
  Do not add name, trigger-type, or country fields without being asked.
- **Server functions return result objects, never throw.** `joinWaitlist` returns
  `{ status: 'joined' | 'already' | 'invalid' | 'error' }` so the form can render
  every outcome inline. Duplicate emails use `onConflictDoNothing` and report
  `already` — a repeat signup is never an error the visitor sees.
- **`getWaitlistCount` returns `null` on failure**, and `CountLine` hides the
  number below 25 signups. A waitlist that says "4 people" is worse than one that
  says nothing, and inventing a number is worse still.
- **Honesty is the brand.** The page states that the product is at prototype
  stage, labels the renders as concepts, gives no ship date, and captions the
  console as an illustration rather than measured performance. Keep any new copy
  to that standard — this audience has been sold false fixes before.
- **Clay (`--color-clay`) is reserved** for the untreated-trigger state in the
  console and form errors. It is the only warm colour in the palette; do not use
  it decoratively.
- **Bar amplitudes are deterministic** (`ROOM_TONE` derives from a fixed sine
  formula, not `Math.random`) so server and client markup match during hydration.
- **Images are static.** They were generated once and committed. There is no
  runtime image generation, and every `<img>` goes through
  `/.netlify/images?url=...&fm=webp` rather than the original PNG.

## Conventions

- Components: PascalCase files exporting a named function. No default exports.
- Tailwind utilities only; semantic colours come from the `@theme` block in
  `src/styles.css` (`bg-ink`, `text-muted`, `border-line`, …). Avoid raw hex in
  components.
- `font-display` (Instrument Serif) for headings, body text stays in Manrope at
  weight 300.
- Animate `transform` and `opacity` only. Respect the
  `prefers-reduced-motion` block already in `styles.css`.
- TypeScript is strict with `noUnusedLocals` — unused imports fail the build.
- Schema changes require a generated migration. Never run `drizzle-kit migrate`
  or `push`, and never apply SQL by hand; Netlify applies migrations on deploy.

## Local development

Use `netlify dev --port 8889` rather than `npm run dev`, so the database and
Image CDN are emulated.
